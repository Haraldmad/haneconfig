# Novo Studio – Stitch Prompt Design 1 (webarchitect dark-luxury)

```markdown
Design a dark-luxury Scandinavian Web-as-a-Service (WaaS) studio landing page for "Novo Studio" (novostudio.se) using the Stitch Web Architect framework (preset: dark-luxury).

Anti-Slop & Styling Directives:
- NO generic AI templates, NO flat plain buttons, NO Inter/Roboto defaults.
- Palette: Obsidian Void background (#09090B), Dark Slate cards (#141417), Champagne Bronze accent (#C9A84C) with subtle glow, Mint Green (#2DD4A0) for SSL & Speed badges, Ivory text (#FAF8F5), Crisp 1px hairline borders (#2A2A35).
- Typography: Plus Jakarta Sans for structural headings, Playfair Display (italic) for dramatic hero statements, Outfit for clean body text, JetBrains Mono for tech metrics & speed stats.

Key Layout Sections:
1. Header: Fixed dark header with border-bottom (#2A2A35), logo "Novo Studio", nav links (Erbjudande, Fördelar, Pris), and Champagne Bronze CTA button with physical depth.
2. Hero Section:
   - Playfair Display Italic statement: "Din nya hemsida – gratis prototyp innan du bestämmer dig."
   - Subheadline: "Blixtsnabb laddtid, inkluderat SSL-certifikat, teknisk SEO och fria ändringar för 500 kr/månad."
   - Signature Component: "Mission Control Audit Card" displaying:
     - ⚡ Google Speed Index: 100/100 (Mint Green badge)
     - 🔒 SSL Security: A+ HTTPS Active (glowing mint indicator)
     - 🚀 Response Time: < 0.2s (JetBrains Mono font)
   - Primary CTA: "Be om ett gratis förslag" with tactile lift & Champagne glow on hover.

3. Asymmetric Bento Grid (6 Advantage Cards):
   - Card 1: Blixtsnabb laddtid (< 0.5s) & 100/100 Google Lighthouse score.
   - Card 2: Inkluderat SSL-Certifikat (HTTPS) – alltid 100% gratis & säkert.
   - Card 3: Teknisk SEO-optimering för högre ranking på lokala Google-sökningar.
   - Card 4: 100% Managed Service – skicka ett SMS så ändrar vi text/bilder inom 24-48h.
   - Card 5: Inga dyra engångsutgifter på 30 000 kr – förutsägbar månadskostnad.
   - Card 6: 3 månaders risktrygg provtid – se prototypen gratis i förväg.

4. Pricing Card:
   - Featured Card: "Novo Studio Abonnemang"
   - Trial Price: "1 000 kr / mån" (Månad 1–3 provtid)
   - Regular Price: "500 kr / mån" (Månad 4+)
   - Included checklist: Hosting, SSL, SEO, Drift, Fria ändringar.

5. Lead Capture Form:
   - 3-input card: Företagsnamn, Stad/Bransch, E-post/Telefon, and button "Skapa mitt gratis förslag".

Execution Quality: Crisp 1px hairline borders (#2A2A35), generous vertical padding, responsive layout down to mobile.
```
