# Novo Studio – Stitch Prompt Design 2 (minimal-editorial)

```markdown
Design an anti-slop, high-fashion Scandinavian Editorial Web-as-a-Service (WaaS) studio landing page for "Novo Studio" (novostudio.se) using the Stitch Web Architect framework (preset: minimal-editorial).

STRICT STYLING & ANTI-SLOP DIRECTIVES (DO NOT VIOLATE):
- DO NOT use any rounded cards, pills, or grey boxes. Border radius MUST be 0px everywhere (sharp editorial corners like a print catalog).
- DO NOT use generic 3-column card grids. Structure the page as a 2-column broadsheet print layout with vertical 1px hairline dividers (#D4C8B8).
- Background MUST be Warm Paper Linen (#FAF7F2), text MUST be Deep Ink Walnut (#1A1714).
- Primary buttons MUST have 0px sharp corners, 1px solid border (#1A1714), and invert color on hover (like ink soaking into paper).

Typography & Hierarchy:
- Display Hero Statement: Fraunces (Italic 700, 4.5rem font size) or Cormorant Garamond (Italic 300).
- Headings: Libre Baskerville (700) or Space Grotesk.
- Body Text: Inter (400, 16px, line-height 1.8).
- Metrics & Speed Data: DM Mono (500, tabular-nums).

1. Header:
   - Centered editorial logo "NOVO STUDIO" in large Fraunces Italic, flanked by minimal nav links (Erbjudande, Fördelar, Pris) separated by thin vertical hairline rules.
   - Right: Sharp 0px button "Se gratis prototyp".

2. Hero Section (Editorial Broadsheet Layout):

3. Broadsheet Advantage Grid (6 Editorial Rows with 1px dividers):

5. Minimal Contact Form:

Execution Quality: Print-magazine level typography, 0px sharp corners, generous whitespace, 1px hairline dividers (#D4C8B8), completely free of AI slop.
```
