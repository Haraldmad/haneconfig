# Novo Studio – Stitch Prompt Design 2 (webarchitect nordic-showcase)

```markdown
Design a clean, bright Scandinavian Web-as-a-Service (WaaS) studio landing page for "Novo Studio" (novostudio.se) using the Stitch Web Architect framework (preset: saas-clean / nordic-showcase).

Aesthetic & Theme:
- Light Mode Palette: Nordic Pure Off-White background (#FAF9F6), Crisp Pure White cards (#FFFFFF), Deep Graphite Black text (#18181B), Electric Nordic Blue accent (#2563EB) with soft shadow, Emerald Green (#059669) for SSL & Speed badges, Amber Accent (#D97706), Crisp hairline borders (#E4E4E7).
- Typography: Bricolage Grotesque or Plus Jakarta Sans for sculptural modern headings, Outfit / DM Sans for clean body text, JetBrains Mono for tech metrics & speed stats.

Key Layout Sections:
1. Header: Minimalist light header with logo "Novo Studio", nav links (Erbjudande, Fördelar, Pris), and an Electric Blue CTA button "Be om prototyp" with physical depth.
2. Hero Section:
   - Headline: "Vi bygger din nya hemsida gratis i förväg – se potentialen."
   - Subheadline: "Blixtsnabb laddtid, inkluderat SSL-certifikat, teknisk SEO och fria ändringar för 500 kr/månad."
   - Signature Component: "Interactive Industry Showcase & Speed Audit Card" with tabbed preview for:
     - 🛠️ Hantverkare & Snickare: Live preview card with 100/100 Speed, click-to-call button & SSL badge.
     - ✂️ Frisör & Skönhet: Mobile-first gallery preview with booking link & <0.3s load speed.
     - 🍽️ Restaurang: Menu layout preview with HTTPS green badge.
   - Primary CTA: "Be om ett gratis förslag" with subtle blue glow on hover.

3. Asymmetric Bento Grid (6 Showcase Advantage Cards):
   - Card 1: Blixtsnabb laddtid (< 0.3s) & 100/100 Google Lighthouse score with live score badge.
   - Card 2: Inkluderat SSL-Certifikat (HTTPS) – alltid 100% gratis & säkert.
   - Card 3: Teknisk SEO-optimering för högre ranking på lokala Google-sökningar.
   - Card 4: 100% Managed Service – skicka ett SMS så ändrar vi text/bilder inom 24-48h.
   - Card 5: Inga dyra engångsutgifter på 30 000 kr – förutsägbar månadskostnad.
   - Card 6: 3 månaders risktrygg provtid – se prototypen gratis i förväg.

4. Pricing Card:
   - Clean White Card: "Novo Studio Abonnemang"
   - Trial Price: "1 000 kr / mån" (Månad 1–3 provtid)
   - Regular Price: "500 kr / mån" (Månad 4+)
   - Included checklist: Hosting, SSL, SEO, Drift, Fria ändringar.

5. Lead Capture Form:
   - Clean 3-input card: Företagsnamn, Stad/Bransch, E-post/Telefon, and button "Skapa mitt gratis förslag".

Execution Quality: Ultra-clean Scandinavian aesthetic, crisp 1px hairline borders (#E4E4E7), generous whitespace, tactile buttons with depth, responsive down to mobile.
```
